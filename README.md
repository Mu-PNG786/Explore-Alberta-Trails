``Explore Alberta Trails

Project Overview

Explore Alberta Trails is a responsive hiking information website developed as part of Assessment Part 4. The project demonstrates web development, debugging, security hardening, deployment, and maintenance planning practices.

The website provides:

- Alberta hiking and outdoor content
- Current weather information using the Open\-Meteo API
- Responsive design for desktop and mobile devices
- Embedded trail video content
- Accessibility and security improvements

Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Open\-Meteo Weather API
- GitHub Pages

Refactoring and Improvements

The original scaffold contained multiple issues affecting:

- HTML validity
- Security
- Accessibility
- Performance
- Maintainability

The following improvements were implemented:

HTML

- Added language declaration
- Added SEO\-friendly title and description
- Fixed invalid form structure
- Fixed broken tags
- Added image alt attributes

CSS

- Removed unused Bootstrap dependency
- Eliminated duplicate styling
- Improved responsive layouts
- Optimized image usage

JavaScript

- Removed global variable leakage
- Added API error handling
- Removed unused code
- Improved maintainability

Security

- Replaced HTTP resources with HTTPS
- Added secure cookie settings
- Added SameSite cookie protection
- Improved third\-party privacy settings
